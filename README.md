## 📖 Sobre o Projeto

**ATIA** (*Aprendizado em Tecnologias de Inteligência Artificial*) é um curso online completo e gratuito sobre Inteligência Artificial e as novas oportunidades que ela cria no mercado digital.

Baseado no manual "A Tsunami da Inteligência Artificial e as Novas Oportunidades Digitais" e atualizado com as mais recentes inovações de 2025, incluindo:

- 🤖 **GPT-5, Claude 4, Gemini 2.5 Pro** - Modelos mais recentes
- 💼 **Novas Profissões 2025** - Prompt Engineer, AI Ethics Specialist, MLOps
- 🛠️ **Ferramentas No-Code** - Zapier Agents, Make.com, Latenode
- ⚖️ **Regulamentação Atual** - EU AI Act, Brazil AI Act

## 🎯 Estrutura do Curso

### 🌟 Nível 1: Fundamentos (4-6 horas)
1. O Tsunami da IA - Compreendendo a Revolução Digital
2. Transformação Digital e o Novo Mercado de Trabalho
3. Engenharia de Prompt - A Nova Linguagem do Futuro
4. Engenharia de Contexto - Criando Ecossistemas Inteligentes
5. Automação de Processos Empresariais com IA

### ⚡ Nível 2: Aplicação (5-7 horas)
6. GPTs Personalizados e Agentes de IA
7. As Novas Profissões da Era da IA
8. Criação de Conteúdo e Marketing Digital com IA
9. Prospecção e Vendas Automatizadas
10. Educação e Desenvolvimento de Habilidades na Era IA

### 👑 Nível 3: Estratégico (3-4 horas)
11. Ética, Governança e Responsabilidade em IA
12. Implementação Estratégica de IA nas Organizações
13. O Futuro do Trabalho e da Sociedade
14. Guia Prático de Implementação

**Duração Total:** 12-15 horas

## 🚀 Acesso ao Curso

### 🌐 Online (GitHub Pages)
**[Acessar Curso →](https://inematds.github.io/ATIA/)**

### 💻 Local

1. Clone o repositório:
```bash
git clone https://github.com/inematds/ATIA.git
cd ATIA
```

2. **IMPORTANTE:** Use um servidor local (necessário para carregar conteúdo markdown):

```bash
# Opção 1: NPM (recomendado)
npm start
# Acesse: http://localhost:8080

# Opção 2: NPM com auto-open
npm run dev

# Opção 3: Python
python -m http.server 8080

# Opção 4: Node.js direto
npx http-server -p 8080
```

⚠️ **Nota:** Não abra o `index.html` diretamente no navegador (`file://`), pois causará erros de CORS ao carregar os capítulos markdown.
